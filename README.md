# Lopez Solutions Software

Official website for [lopezsolutions.io](https://lopezsolutions.io).

## Stack

- **Frontend:** React + Vite + Tailwind CSS
- **Backend / CMS:** Strapi v5 + PostgreSQL
- **Web server:** Nginx (reverse proxy + SSL via Let's Encrypt)
- **Hosting:** AWS Lightsail
- **Domain / DNS:** Namecheap

## Repository layout

```
.
├── frontend/   # React + Vite + Tailwind — public marketing site
├── backend/    # Strapi v5 CMS + PostgreSQL
├── nginx/      # Production Nginx configuration
└── docs/       # Deployment guides (Lightsail, Namecheap DNS, SSL)
```
