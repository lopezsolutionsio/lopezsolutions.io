Un sitio estático simple:

- **Astro** para generar HTML en build time.
- **MDX** para escribir posts con componentes embebibles.
- **Tailwind CSS v4** para los estilos, con tokens de marca propios.
- **Cloudflare Pages** para hosting gratuito con CDN global.

Cero backend, cero base de datos, cero mantenimiento.
