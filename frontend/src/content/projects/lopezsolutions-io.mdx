A simple static site:

- **Astro** to generate HTML at build time.
- **MDX** to write posts with embeddable components.
- **Tailwind CSS v4** for styling, with custom brand tokens.
- **Cloudflare Pages** for free hosting with a global CDN.

No backend, no database, no maintenance.
